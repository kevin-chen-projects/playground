# AGENTS.md

This repo's agent guidance lives in **[CLAUDE.md](CLAUDE.md)** — a single canonical file
so Claude, GPT/Codex, and other assistants all read the same instructions.

Please read [CLAUDE.md](CLAUDE.md) before working here. In short:

- Mostly **single-file vanilla HTML/CSS/JS sites, no build step** — open in a browser.
- Catalog: [SITES.md](SITES.md). Engineering map: [PLAYGROUND_NOTES.md](PLAYGROUND_NOTES.md). Keep both current when you add/change a site.
- Read each `.html` file's **top TOC comment** before editing.
- **Never `git add .`** — parallel work is in the tree; stage your files by name, branch off latest `origin/main`.
- Source-available license: no commercial reuse / derivatives.
