GUITAR MP3/WAV TRANSCRIPTION - START HERE
=========================================

Goal: open the website, upload an MP3 or WAV, download a PDF + MusicXML.


WINDOWS (easiest)
-----------------
1. Make sure Python is installed. If not, get it from:
      https://www.python.org/downloads/
   On the FIRST installer screen, tick "Add Python to PATH".

2. Double-click  start.bat

3. Wait. The first run installs components (a few minutes, needs internet).
   Your browser will open to the app automatically when it's ready.

4. In the website:
   - Upload an MP3 or WAV
   - Click "Generate Outputs"
   - Download the PDF and MusicXML

5. To stop: close the browser tab, then press Ctrl+C in the black window
   (or just close the window).


MAC
---
Double-click  start.command  (or run  python3 start.py  in a terminal).


IF SOMETHING GOES WRONG
-----------------------
The most common issue is the first-run dependency install failing.
If that happens, copy the text from the black terminal window and send it
back to the person who shared this app.
